01 · Embedded Control System in Action

Control-System Use Case: Speed Supervision and Fault Handling

For this demonstration, I selected a speed-supervision use case to integrate PLC command sequencing with an embedded C controller.

The PLC manages operating requests, while the C controller processes simulated encoder feedback, monitors speed and faults, and generates drive requests.

The recorded scenario demonstrates normal operation, overspeed detection, fault latching and controlled recovery.

PLC sequence
Handles Start, Stop and Reset requests and checks the C controller’s reported state.

C controller
Calculates speed from encoder pulses, detects faults, manages operating states and controls the drive request.

Modeled drive
Shows whether the controller requests the drive ON or OFF. No physical motor is connected.

Encoder feedback goes directly to the C controller.

Overspeed Protection & Controlled Recovery

The controller checks speed feedback at each execution step to detect overspeed and initiate a defined protective response.

At 300 rpm, the controller permits normal operation. When simulated speed reaches 900 rpm, exceeding the 600 rpm demonstration limit, it detects overspeed, enters FAULT, requests the drive to stop and latches the fault.

To prevent unintended restart, restoring normal feedback alone does not resume operation. The controller requires a valid Reset followed by a separate Start command.

Automated tests verify that the fault response is triggered correctly, Start cannot bypass an active fault, and Reset alone keeps the drive request OFF.

#include "drive_controller.h"

void drive_init(struct drive *d) { *d=(struct drive){.state=READY}; }
static enum drive_result trip(struct drive *d,enum drive_fault reason)
{
 d->state=FAULT;d->fault=reason;d->drive_request=false;return FAULT_HELD;
}
bool drive_speed_fresh(const struct drive *d)
{ return d->have_sample && d->now_ms-d->sample_ms<=SAMPLE_TIMEOUT_MS; }

enum drive_result drive_step(struct drive *d,struct drive_input in)
{
 /* Reject invalid time/sample before touching any controller state. */
 if(in.now_ms<d->now_ms)return INVALID_TIME;
 if(in.sample_available && d->have_sample && in.now_ms==d->sample_ms && in.encoder_count!=d->encoder_count)return INVALID_SAMPLE;
 d->now_ms=in.now_ms;
 /* Late data cannot erase a deadline which already expired. */
 if(d->state==STARTING && in.now_ms-d->start_ms>STARTUP_GRACE_MS)return trip(d,STARTUP_TIMEOUT);
 if(d->state==RUNNING && in.now_ms-d->pulse_ms>SAMPLE_TIMEOUT_MS)return trip(d,ENCODER_TIMEOUT);
 bool too_fast=false;
 if(in.sample_available){
  if(d->have_sample && in.now_ms>d->sample_ms){
   uint32_t elapsed=in.now_ms-d->sample_ms;
   uint32_t delta=in.encoder_count-d->encoder_count; /* Single unsigned counter wrap is supported. */
   uint64_t measured=(uint64_t)delta*60000U;
   uint64_t denominator=(uint64_t)PULSES_PER_REVOLUTION*elapsed;
   d->pulse_delta=delta;d->rpm_milli=measured*1000U/denominator;
   too_fast=speed_exceeds_limit(measured,(uint64_t)DEMO_LIMIT_RPM*denominator);
   if(delta){d->pulse_ms=in.now_ms;d->stationary_confirmed=false;}
   else if(elapsed>=SAMPLE_TIMEOUT_MS){d->stationary_confirmed=true;d->stationary_ms=in.now_ms;}
  }
  d->have_sample=true;d->sample_ms=in.now_ms;d->encoder_count=in.encoder_count;
 }
 if(d->state==FAULT){
  d->drive_request=false;
  if(in.command==RESET){
   if(!drive_speed_fresh(d) || !d->stationary_confirmed || in.now_ms-d->stationary_ms>SAMPLE_TIMEOUT_MS || d->rpm_milli)return RESET_DENIED;
   d->state=READY;d->fault=NO_FAULT;return OK;
  }
  return FAULT_HELD;
 }
 if(too_fast && (d->state==STARTING || d->state==RUNNING))return trip(d,OVERSPEED);
 if(in.command==STOP){d->state=READY;d->drive_request=false;return OK;}
 if(d->state==STARTING && in.sample_available && d->pulse_delta && d->rpm_milli && drive_speed_fresh(d))d->state=RUNNING;
 if(in.command==START && d->state==READY){
  d->state=STARTING;d->drive_request=true;d->start_ms=in.now_ms;d->pulse_ms=in.now_ms;
  /* A new start needs new pulses, not an old speed observation. */
  d->pulse_delta=0;d->stationary_confirmed=false;
 }
 return OK;
}
const char *drive_state_name(enum drive_state value)
{ switch(value){case READY:return "READY";case STARTING:return "STARTING";case RUNNING:return "RUNNING";case FAULT:return "FAULT";}return "UNKNOWN"; }

{ switch(value){case NO_FAULT:return "NONE";case STARTUP_TIMEOUT:return "STARTUP_TIMEOUT";case ENCODER_TIMEOUT:return "ENCODER_TIMEOUT";case OVERSPEED:return "OVERSPEED";}return "UNKNOWN"; }
PLC sequence · operator_sequence.st
(* PLC owns operation sequencing. C owns encoder supervision. *)
FUNCTION_BLOCK OperatorSequence
VAR_INPUT
    StartButton : BOOL;
    StopButton : BOOL;
    ResetButton : BOOL;
    ControllerState : INT; (* 0 Ready, 1 Starting, 2 Running, 3 Fault *)
    NowMs : UDINT;
END_VAR
VAR_OUTPUT
    Command : INT;       (* 0 None, 1 Start, 2 Stop, 3 Reset *)
    SequenceState : INT; (* 0 Ready, 1 Starting, 2 Running, 3 Fault *)
    FaultReason : INT;   (* 0 None, 1 Start not confirmed, 2 C fault *)
END_VAR
VAR
    StartAtMs : UDINT;
    ResetPending : BOOL;
END_VAR
VAR CONSTANT
    READY : INT := 0;
    STARTING : INT := 1;
    RUNNING : INT := 2;
    FAULT : INT := 3;
END_VAR

Command := 0;
IF StopButton THEN
    Command := 2;
    IF ControllerState <> FAULT THEN SequenceState := READY; END_IF;
ELSIF ControllerState = FAULT THEN
    SequenceState := FAULT;
    FaultReason := 2;
    IF ResetButton THEN Command := 3; ResetPending := TRUE; END_IF;
ELSIF SequenceState = FAULT THEN
    IF (ResetPending OR ResetButton) AND (ControllerState = READY) THEN
        Command := 3;
        SequenceState := READY;
        FaultReason := 0;
        ResetPending := FALSE;
    END_IF;
ELSIF SequenceState = STARTING THEN
    IF ControllerState = RUNNING THEN
        SequenceState := RUNNING;
    ELSIF NowMs - StartAtMs > 500 THEN
        SequenceState := FAULT;
        FaultReason := 1;
        Command := 2;
    END_IF;
ELSIF SequenceState = RUNNING THEN
    IF ControllerState = READY THEN SequenceState := READY; END_IF;
ELSIF StartButton AND (ControllerState = READY) THEN
    Command := 1;
    SequenceState := STARTING;
    StartAtMs := NowMs;
END_IF;
END_FUNCTION_BLOCK

03 · Automated Verification & Regression Detection

To detect software defects before deployment to a controller, I combined automated behavioral tests, regression checks and static analysis. For this demonstration, I introduced a defect that still compiled and checked whether the verification workflow rejected it before accepting the software change.

I deliberately changed only the speed-policy function. The controller, PLC logic and test assertions remained unchanged.

Working implementation

speed_policy.c · C function

bool speed_exceeds_limit(uint64_t measured,
                         uint64_t limit)
{
    return measured > limit;
}

True means the measured speed exceeds the limit.

Deliberately injected defect

speed_policy.c · C function

bool speed_exceeds_limit(uint64_t measured,
                         uint64_t limit)
{
    return (measured > limit) && false;
}

Always returns false, so overspeed is never reported.
