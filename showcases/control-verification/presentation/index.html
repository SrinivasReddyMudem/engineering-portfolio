2 · The code compiles. Does protection still work?

I deliberately changed only the speed-policy function. The controller, PLC logic and test assertions remained unchanged.

Working comparison
return measured > limit;

True means speed is excessive.

Deliberately injected defect
return (measured > limit) && false;

The result is always false, so overspeed is never reported.

Why this matters: successful compilation checks whether code can be built. Behavioral tests check whether it still meets the required operating contract.
